## 运算

如果不同精度的张量在 torch 中发生运算，有些情况会将低精度的张量升到与另一张量同样的精度进行计算，常见的是「加减乘除」：

```python
x = torch.randn((2, 3))
y = torch.randn((2, 3)).bfloat16()

print((x + y).dtype)
# torch.float32
print((x * y).dtype)
# torch.float32
```

运算结果是较高精度的，但如果两个张量发生「原地操作」，那么精度跟被原地操作的张量精度一致，但如果不是原地操作，就会发生精度上升。 这种现象的原因是原地操作还需要存回原来张量的内存，而直接赋值会将原来张量的内存地址改到运算结果的

```python
y += x # in-place
print(y.dtype)
# torch.bfloat16

y = x + y
print(y.dtype)
# torch.float32
```

> [!warning] 如果是 Linear，Conv2d 这种高度优化的算子，其底层的 C++/CUDA 代码并没有适配 weight 和 x 不同的数据类型，则会报错

## 其他操作

当发生不同精度张量的拼接时，也会自动上升精度：

```python
x = torch.randn((2, 3))
y = torch.randn((2, 3)).bfloat16()
print(torch.cat([x, y]).dtype)
# torch.float32
```
