给定参与归一化的元素，$x_{1}, x_{2}, \dots, x_{n}$，那么 Batch Normalization[^1] (BN) 为：

$$
\begin{align*}
\mathbb{E}[\boldsymbol{x}] &= \frac{1}{n}\sum_{i}^{n} x_{i}\\
\mathbb{V}[\boldsymbol{x}] &= { \frac{1}{n} \sum_{i}^{n} (x_{i} - \mathbb{E}[\boldsymbol{x}])^{2}}\\
\bar{x}_{i} &= \gamma \cdot\frac{{x_{i} - \mathbb{E}[\boldsymbol{x}]}}{\sqrt{ \mathbb{V}[\boldsymbol{x}] + \epsilon }} + \beta
\end{align*}
$$

令所有元素都变成之前的 $k$ 倍：$x_{i}' = kx_{i}$，那么：

$$
\begin{align*}
\mathbb{E}[\boldsymbol{x}'] &= \frac{1}{n} \sum_{i}^{n} kx_{i} = k\mathbb{E}[\boldsymbol{x}]\\
\mathbb{V}[\boldsymbol{x}'] &= { \frac{1}{n} \sum_{i}^{n}(kx_{i} - \mathbb{E}[\boldsymbol{x}'])^{2}} = k^{2}\mathbb{V}[\boldsymbol{x}]\\
\bar{x_{i}'} &= \gamma \cdot \frac{{kx_{i} - k\mathbb{E}[\boldsymbol{x}]}}{\sqrt{ k^{2}\mathbb{V}[\boldsymbol{x}] + \epsilon }} + \beta ={\color{#08F}  \bar{x}_{i} \iff \epsilon = 0}
\end{align*}
$$

当且仅当 $\epsilon=0$ 时，进 BN 前的系数被吸收了，即「尺度不变性」：

$$
\text{BN}(kx) = \text{BN}(x)
$$

当然，这性质不止 BN 成立，对 Layer Norm 以及 RMSNorm 也成立

不过注意实际使用时 $\epsilon=0.00001$，也就是并不等价：

```python
x = torch.randn(3, 4)
bn = nn.BatchNorm1d(num_features=4)
torch.testing.assert_close(bn(x), bn(10 * x))
# AssertionError: Tensor-likes are not close!

# Mismatched elements: 5 / 12 (41.7%)
# Greatest absolute difference: 0.00022232532501220703 at index (1, 1) (up to 1e-05 allowed)
# Greatest relative difference: 0.0001767474750522524 at index (0, 1) (up to 1.3e-06 allowed)
```
